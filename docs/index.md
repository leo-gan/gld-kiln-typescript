# gld-kiln-typescript

A from-scratch Kiln codec for TypeScript. The package is `gld-kiln`. The generator command is `gld-kilngen-typescript`.

The library encodes and decodes Frozen values and a version-2 tensor directory. It does not wrap another Kiln implementation.
